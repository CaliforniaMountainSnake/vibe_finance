# Тесты

## `unit`

Юнит-тесты: чистые функции, бизнес-логика, утилиты, хелперы.

Без сайд-эффектов — не обращаются к файловой системе, БД или сети. Запускаются в среде Node без DOM.

## `integration`

Интеграционные тесты с сайд-эффектами: запросы к реальным API, работа с базой данных, запись/чтение файлов, взаимодействие с внешними сервисами.

Могут быть медленными и недетерминированными.

## `react`

Тоже юнит-тесты, но проверяющие рендеринг React-компонентов в виртуальном DOM (jsdom).

Используется [React Testing Library](https://testing-library.com/react) — компонент рендерится через `render()`, действия симулируются через `userEvent`, проверки выполняются на реальном DOM-дереве.
