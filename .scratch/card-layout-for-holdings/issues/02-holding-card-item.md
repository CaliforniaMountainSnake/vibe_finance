## What to build

Создать компонент `HoldingCardItem` — карточку одного средства на shadcn `Card` (`size="sm"`):

```
┌──────────────────────────────────┐
│ 🔷 1 234,56 ₾           [✏️][⋮] │  ← CardHeader: CardTitle + CardAction
│ ≈ 45,67 USD                      │  ← CardContent: конверт + название счёта
│ Карточка синего банка            │
└──────────────────────────────────┘
```

**Детали:**

- `CardTitle`: иконка источника (`SourceIcon`), сумма (`formatAmount(holding.amount)`), unit (из `holding.ticker`).
- `CardAction`: кнопка редактирования [✏️] + кебаб-меню [⋮] (переместить вверх/вниз, учитывать/не учитывать в итоге, удалить). Действия унифицированы — без разделения на Mobile/Desktop варианты.
- Конвертированная сумма (`≈ X Y`) показывается только если валюта holding не совпадает с итоговой (`isSameCurrency`).
- Название счёта — без обрезки, с переносом строк.
- Тултип с курсом конверсии при наведении на сумму (как сейчас в `HoldingTooltip`).
- Disabled-состояние: `opacity-40` на всей карточке.

Пропсы: `holding`, `conversionRate`, `totalTicker`, колбэки (`onEdit`, `onMoveUp`, `onMoveDown`, `onToggleEnabled`, `onRemove`, `isFirst`, `isLast`).

Удалить `HoldingRow.tsx` после того, как его логика полностью мигрирует в новый компонент.
