# Card-based layout for holdings list

Перешли с табличного (`<Table>`) отображения списка средств на карточную раскладку (shadcn `Card`). Причина: на узких экранах мобильных устройств таблица требовала горизонтального скролла из-за длинных названий счетов. Карточки располагают информацию вертикально, полностью исключая скролл при любом размере шрифта.

Единый лейаут на всех разрешениях — один столбец карточек с компактным размером (`size="sm"`). Итоговая сумма выделена в отдельную карточку с muted-фоном.
